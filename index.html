04 myDATA IntegrationΕνσωμάτωση myDATA

No native Zoho–myDATA integration exists. The entire myDATA layer must be built as a custom integration within Zoho Creator, communicating with AADE's API. This is a legal requirement — the integration operates as an invisible backend process within the Zoho environment.Δεν υπάρχει εγγενής ενσωμάτωση Zoho–myDATA.
